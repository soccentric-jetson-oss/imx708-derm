# Changelog

## v0.1.0 (2026-08-05)
- Initial imx708-derm implementation
- Real-time skin imaging pipeline with 7 stages
- Dual-camera capture via GStreamer
- Frame registration with affine transform
- HSV-based skin segmentation
- ROI feature extraction (moments, area)
- Multi-camera fusion with weighted blending
- Control loop with PWM output simulation
- Per-stage latency instrumentation
- CMake build system with OpenCV
